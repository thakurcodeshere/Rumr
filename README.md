# Rumr — Topic-First Social Discovery

> **Topic > Person.** An anonymous, encrypted social discovery and debate network balancing high-end brutalist editorial aesthetics with intellectual friction.

---

## ⚡ Highlights

- **Clean Chaos Theme:** Brutalist-lite dark mode, 0px border-radius, 2px neon borders, 4px hard offset purple shadows (`#a855f7` & `#ccff00`).
- **66-Screen Master Catalog:** Full interactive UI mapping and live renderer for all 66 project designs.
- **Encrypted Rumor Unmasking:** Interactive blur-to-text transitions on verified whispers.
- **4-Stage Progressive Reveal Chat:** Real-time ephemeral topic chat with mutual identity unmasking and celebration physics.
- **Live Audio Topic Rooms:** Spatial audio debate spaces with moderator podiums and speaker mics.
- **Topic Matrix & Radar:** Custom debate node creation, heat scores, and compatibility vectors.
- **Topic Amplifier (Pro):** Boost monetization tiers, impression simulation, and checkout flows.
- **AI Toxicity Sentinel:** Real-time ad-hominem detection and cryptographic incident reporting.

---

## 🛠️ Tech Stack

- **Framework:** [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) + Custom Brutalist Physics
- **Icons:** [Lucide React](https://lucide.dev/)
- **Animations & Effects:** [Framer Motion](https://www.framer.com/motion/) + [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **State Management:** Reactive React Context Store

---

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/thakurcodeshere/Rumr.git
cd Rumr
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
