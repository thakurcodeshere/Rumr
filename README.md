## 🧠 Core Philosophy: The Clean Chaos System

```
  ┌────────────────────────────────────────────────────────┐
  │ 01. Topic > Person        Matching on thoughts, not faces. │
  │ 02. ≤ 3 Words Constraint  Hard token limits stop slander.  │
  │ 03. 3-Layer Unmasking     Consent-governed identity reveal.│
  │ 04. Ephemeral Telemetry   Zero unhashed permanent storage. │
  └────────────────────────────────────────────────────────┘
```

1. **Topic-First Matching**: Users react to specific, high-friction debate nodes in their locality. You only match with individuals who share deep philosophical alignment or compelling contrarian tension.
2. **The ≤ 3-Word Hard Constraint**: All user-created topic nodes are restricted to 3 words or fewer (*e.g., "Office Politics", "AI Layoffs Reality", "Ghosting Culture"*). Rumr's real-time AI vector moderation prevents targeted slander and transforms toxic impulses into sociological debates.
3. **Progressive Cryptographic Unmasking**: Identity is unlocked through a bilateral 3-step consent protocol:
   - **Layer 1 (Signals)**: Demographic signals (City & Professional Domain).
   - **Layer 2 (Resonance)**: Personal tagline, worldview quote, and Chaos Index compatibility score.
   - **Layer 3 (Decryption)**: Real unblurred portrait, full verified name, and Tier II communication channels.

## 🛠️ Feature Matrix & Architecture

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                                RUMR ENGINE                                   │
├──────────────────────┬────────────────────────┬──────────────────────────────┤
│ 1. DISCOVERY FEED    │ 2. TOPIC CREATOR       │ 3. MATCHES MATRIX            │
│ 4-Vector Similarity  │ ≤ 3-Word AI Guard      │ Shared Affinity Overlaps     │
│ Demographic Sliders  │ Geospatial broadcast   │ Instant Tunnel Initiator     │
├──────────────────────┼────────────────────────┼──────────────────────────────┤
│ 4. ENCRYPTED CHATS   │ 5. AUDIO DEBATES       │ 6. DUAL-PROFILE "ME"         │
│ 3-Stage Unmasking    │ Spatial WebRTC stages  │ Chaos Profile (Resonance)    │
│ Ephemeral Decay (~5m)│ Moderated audio podium │ Settings (Ghost Mode / DPDP) │
└──────────────────────┴────────────────────────┴──────────────────────────────┘
```

### 1. Topic-First Discovery Engine
- **Algorithmic Selectors**: Choose between 4 distinct similarity modes (*Exact Match, Related Topics, Balanced Chaos, Exploratory Contrarian*).
- **Proximity & Demographic Bounds**: Dual age-range sliders (18–45+), gender affinity toggles, and customizable radius filters (Nearby, City, Global).

### 2. Encrypted Match Reveal Moment
- Double-tilted holographic card reveal screen with glitched avatar mask, `[SYNC_ESTABLISHED]` beacon, `UNKNOWN_` cryptographic handle, and real-time topic overlap chips.

### 3. Match List & Active Topic Tunnels
- Dedicated encrypted inbox listing all mutual topic connections with compatibility scores, unmasking stage badges, and message previews.
- Instant transition to ephemeral 1-on-1 tunnels with cryptographic message decay timers.

### 4. Interactive 3-Layer Mutual Unmasking Protocol
- Dedicated step-by-step cryptographic consent modal (`MutualUnmaskingModal.tsx`) allowing users to progressively authorize each layer of identity reveal.
- Final unlocked moment renders the full **Identity Decrypted Card** with verified human badges, match metrics, revealed interests, and Tier II communication channels.

### 5. Dual-Profile "Me" Architecture
- **Tab 1: Chaos Profile**: Displays user age badge, connection counters, active rumors index, ≤ 3-word topic injector, and locked topic vault.
- **Tab 2: Profile Settings**: Global discovery radius, Ghost Mode broadcasting toggle, Account Dynamics (Verification status & DPDP export), Blocked Entities, and Terminate Session.

### 6. Dedicated Standalone Marketing Landing Website
- Zero-dependency responsive HTML5 / Tailwind marketing website served at `/landing.html` complete with App Store / Google Play store badges, telemetry tickers, architectural essays, and functional contact forms.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0.0 or higher)
- [npm](https://www.npmjs.com/) (v9.0.0 or higher)

### 1. Clone the repository
```bash
git clone https://github.com/thakurcodeshere/Rumr.git
cd Rumr
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.  
To view the standalone marketing website, navigate to [http://localhost:5173/landing.html](http://localhost:5173/landing.html).

### 4. Build for production
```bash
npm run build
```
